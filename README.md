# Pipelined RISC-V Processor

This repository contains my implementation of a pipelined RISC-V processor using SystemVerilog.

The design includes:

- Datapath
- Controller and instruction decoders
- ALU
- Register file
- Instruction and data memory
- Pipeline registers
- Hazard detection and forwarding logic
- Multiplexers and supporting modules

The repository also includes diagrams of the CPU, datapath, controller, memories, and decoders.

## Tools Used

- SystemVerilog
- Icarus Verilog
- GTKWave

This project was developed to better understand pipelined processor architecture and RISC-V implementation.
